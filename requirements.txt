# SceneFactory Python dependencies.

# ---------------------------------------------------------------------------
# THIS FILE IS NOT SUFFICIENT ON ITS OWN.
#
# SceneFactory depends on NVIDIA Isaac Sim and Isaac Lab, which are NOT
# installable from this file:
#
#   * Isaac Sim 5.1.0 is distributed through NVIDIA's package index, not PyPI,
#     and pulls ~14 GB of extension caches.
#   * Isaac Lab is installed from a git checkout in editable mode, and its
#     version must match the Isaac Sim version.
#
# Install those two first, following README.md "Installation" steps 2 and 3,
# then run:
#
#     pip install -r requirements.txt
#
# Versions below are the ones verified end-to-end on Python 3.11 / Linux.
#
# Known upstream conflict: pip reports that Isaac Sim's fastapi pin and Isaac
# Lab's starlette pin disagree (and likewise typing_extensions). This is not
# caused by this file and appears regardless of install order. It did not block
# installation in our runs.
# ---------------------------------------------------------------------------
